# Нүүр хуудасны "Hannah Styling" зургийн хэсэг

Зургаа **энэ хавтсанд** хийнэ. Жишээ нь:

```
public/images/gallery/1.jpg
public/images/gallery/2.jpg
...
```

Дараа нь `src/components/home/gallery.tsx` файлын дээд хэсэгт байгаа
`GALLERY` жагсаалтыг доорх шиг болгож солино:

```ts
const GALLERY = [
  { src: "/images/gallery/1.jpg", alt: "Намрын цуглуулга" },
  { src: "/images/gallery/2.jpg", alt: "Өдөр тутмын хувцас" },
  // ...
];
```

`public` гэдэг үгийг замд БИЧИХГҮЙ — `/images/gallery/1.jpg` гэж эхэлнэ.

## Зөвлөмж

- **Харьцаа:** 1:1 (дөрвөлжин). Жишээ нь 800×800 эсвэл 1200×1200.
  Өөр харьцаатай зургийг дунд хэсгээс нь автоматаар тайрна.
- **Хэмжээ:** 800px-ээс өргөн. Next.js өөрөө жижигрүүлж, WebP болгоно.
- **Файлын нэр:** зөвхөн латин үсэг, тоо, зураас. Кирилл үсэг,
  зай ашиглавал зарим browser дээр зураг гарахгүй.
- **Facebook, Instagram-ийн шууд холбоос ашиглахгүй.** Тэдгээр хаяг
  хэдхэн хоногт хүчингүй болж, зураг алга болдог.
