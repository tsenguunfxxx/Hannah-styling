# HANNAH STYLING — брэндийн лого

| Файл | Юу вэ | Хаана хэрэглэх |
|---|---|---|
| `hannah-mark-dark.svg` | Зөвхөн эрвээхэй, бараан | Цайвар дэвсгэр |
| `hannah-mark-light.svg` | Зөвхөн эрвээхэй, цайвар | Бараан дэвсгэр |
| `hannah-logo-dark.svg` | Эрвээхэй + нэр, бараан | Цайвар дэвсгэр |
| `hannah-logo-light.svg` | Эрвээхэй + нэр, цайвар | Бараан дэвсгэр |

Дэвсгэр нь ил тод (transparent) — ямар ч өнгө дээр тавьж болно.

## SVG гэж юу вэ

Энгийн зурган файл (JPG, PNG) нь пикселээс бүрддэг тул томсгоход
бүдгэрдэг. SVG нь ТОМЬЁОГООР зурагддаг — визитийн карт дээр ч,
байшингийн хэмжээний самбар дээр ч ижил хурц харагдана.

Canva, Figma, Illustrator, Word, Photoshop бүгд нээнэ.

## Өнгө солих

Файлыг Notepad/TextEdit-ээр нээгээд дотор нь байгаа өнгөний кодыг солино:

- `#111110` — бараан (брэндийн хар)
- `#f2f1ed` — цайвар (брэндийн цагаан)

## ⚠️ Нэрний фонт

Бүтэн логоны нэр нь **Jost** фонтоор бичигдсэн. Тэр фонт суулгаагүй
компьютер дээр өөр фонтоор орлуулж харагдана.

Үнэгүй татах: https://fonts.google.com/specimen/Jost

Хэрэв фонт суулгахгүйгээр найдвартай ашиглах бол зөвхөн `mark`
файлуудыг (эрвээхэй) хэрэглэнэ — тэдгээр нь фонтоос хамаарахгүй.

## PNG хэрэгтэй бол

Facebook, Instagram профайл зэрэг зарим газар SVG хүлээж авдаггүй.
Ийм үед:

1. SVG файл дээр хоёр товшиж **Preview** программаар нээнэ
2. File → Export → Format: **PNG** → Save

Эсвэл онлайн: [cloudconvert.com/svg-to-png](https://cloudconvert.com/svg-to-png)

Профайл зурагт `hannah-mark-*.svg` (дөрвөлжин) тохиромжтой,
харин баннер, вэб хуудсанд `hannah-logo-*.svg` (өргөн) тохиромжтой.
