# Нүүр хуудасны зураг

Өөрийн зургаа энэ хавтсанд **hero.jpg** нэрээр хадгална.

Дараа нь `src/lib/constants.ts` доторх `HERO.image`-ийг доорх болгож солино:

```ts
export const HERO = {
  image: "/images/inzana.jpg",
  alt: "Намрын шинэ цуглуулга",
} as const;
```

## Зөвлөмж

- **Харьцаа:** 3:4 (босоо). Жишээ нь 1200×1600 эсвэл 1536×2048.
- **Хэмжээ:** 1200px-ээс өргөн. Next.js өөрөө жижигрүүлж, WebP болгоно.
- **Facebook, Instagram-ийн шууд холбоос ашиглахгүй.** Тэдгээр хаяг
  хэдхэн хоногт хүчингүй болж, зураг алга болдог.
